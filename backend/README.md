# Datuk - Cough Detection API

Backend API for cough type classification using TensorFlow.

## Endpoints

- `POST /predict` - Upload audio file for cough classification
- `GET /health` - Health check
- `GET /history` - Get diagnosis history
- `GET /docs` - Swagger API documentation
